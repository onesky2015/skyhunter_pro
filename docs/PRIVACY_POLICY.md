# SkyHunter 隐私政策

**生效日期：** 2026-03-10  
**适用范围：** SkyHunter 航班价格监控服务（iOS App、Android App、Web）

## 1. 我们收集的信息

- **账户信息**：邮箱、密码（加密存储）
- **监控任务**：出发地、目的地、日期、舱位、乘客数、目标价格等
- **使用数据**：积分消耗、搜索记录、通知偏好

## 2. 信息用途

- 提供航班价格监控与降价提醒
- 发送邮件/推送通知
- 计费与积分管理
- 改进产品体验

## 3. 数据存储与安全

- 数据存储在安全云服务（PostgreSQL）
- 密码使用 bcrypt 哈希存储
- API 通信使用 HTTPS

## 4. 第三方服务

- **SerpApi**：航班价格数据查询
- **Brevo/SMTP**：邮件发送
- **Firebase**（可选）：推送通知

## 5. 您的权利

- 查看、更正个人数据
- 请求删除账户及关联数据
- 退订邮件通知（回复邮件即可）

## 6. 联系我们

如有隐私相关问题，请发送邮件至：privacy@skyhunter.app
